# Avi AI — v1

Abhi ಗಾಗಿ Flutter app. WhatsApp + Instagram + Facebook Messenger + GBP —
ಒಂದೇ inbox, AI draft, Abhi approve ಮಾಡಿದಮೇಲೆ ಮಾತ್ರ send.

## v1 ನಿಜ ಸ್ಥಿತಿ (Manual mode — ಇದನ್ನು ಮರೆಯಬೇಡಿ)

- **Direct connect ಇಲ್ಲ:** Facebook personal profile Messenger ಗೆ Meta official API
  ಇಲ್ಲ (Page ಗೆ ಮಾತ್ರ ಇದೆ). Abhi ಅವರ Page ಗೆ followers ಇಲ್ಲ, personal ಮಾತ್ರ
  ಇದೆ, Page ಮಾಡೋಕೆ ಆಗಲ್ಲ. Muse Messenger connect 2026-11-21 ರಲ್ಲಿ
  "something wrong" fail ಆಯ್ತು (Nov 6/10 ರದ್ದೇ Meta-side ಸಮಸ್ಯೆ).
- **WhatsApp personal ಗೆ official API ಇಲ್ಲ** — WhatsApp Business Cloud API ಮಾತ್ರ.
- ಆದ್ದರಿಂದ v1 **manual mode**: ಬಂದ message ಅನ್ನು user paste ಮಾಡುತ್ತಾನೆ →
  Avi AI draft ಮಾಡುತ್ತೆ (ಮೊದಲು Abhi ಅವರ training examples, ಸಿಗದಿದ್ದರೆ
  Kannada template) → Abhi Approve / Edit / Reject ಮಾಡುತ್ತಾನೆ →
  Abhi ಯೇ ಆ app (Messenger / WhatsApp / Instagram) ನಲ್ಲಿ send ಮಾಡುತ್ತಾನೆ.
- **ಏನೂ auto-send ಆಗಲ್ಲ.** Full-access toggle ಇದ್ದರೂ v1 ನಲ್ಲಿ auto-send ಇಲ್ಲ —
  direct connect ಬಂದಮೇಲೆ ಮಾತ್ರ ಅದು ಕೆಲಸ ಮಾಡುತ್ತೆ, ಎಂದು app ನಲ್ಲೇ ಬರೆದಿದೆ.

## Privacy

- App ಫೋನ್ internal memory / files open ಮಾಡಲ್ಲ, scan ಮಾಡಲ್ಲ,
  storage permission ಕೇಳಲ್ಲ. Photo picker ಇಲ್ಲವೇ ಇಲ್ಲ.
- Data phone ನಲ್ಲಿ ಮಾತ್ರ (shared_preferences). No cloud, no API key, no paid API.

## Screens (5 tabs)

1. **Inbox** — unified list, platform filter (WhatsApp / Instagram /
   Facebook / GBP), draft + Approve / Edit / Reject / "ನಾನು send ಮಾಡಿದೆ".
2. **Paste** — ಬಂದ message paste ಮಾಡಿ, profile + platform ಆರಿಸಿ, draft ಪಡೆದು Inbox ಗೆ ಹಾಕಿ.
3. **Train** — Abhi ಕಲಿಸುವ ಜಾಗ: ಬಂದ message → ಅವನ ಉತ್ತರ. ಇವೇ draft logic ನಡೆಸುತ್ತವೆ.
4. **Profiles** — Secrets of Ocean (@secrets_ofocean) + Sisira Mugila Kavite
   (Facebook personal) seed ಆಗಿವೆ; ಹೊಸ profile ಸೇರಿಸಬಹುದು; ಪ್ರತಿ profile ಗೂ
   Approval ಮಾತ್ರ / Full access toggle.
5. **Settings** — approval default, ಭಾಷೆ (ಕನ್ನಡ ಮೊದಲು), privacy note,
   direct-connect status.

  platform-tools, platforms/android-35, build-tools 35.0.0, licenses),
  Gradle 8.12 (`~/.gradle` + `/tmp/gradle-8.12-all.zip`) — ಎಲ್ಲಾ ಸಿದ್ಧ.
- `flutter pub get` ✓, `flutter analyze` — **No issues found!** ✓,
  `flutter test` — **All 3 tests passed!** ✓

**APK ಇಲ್ಲಿ ಆಗಲಿಲ್ಲ — ಕಾರಣ:**
`flutter build apk` (release + debug, 8+ ಪ್ರಯತ್ನ) Gradle daemon handshake
ನಲ್ಲಿ fail ಆಗುತ್ತೆ: daemon start ಆಗುತ್ತೆ, alive ಇರುತ್ತೆ, ಆದರೆ client ಗೆ
"Could not receive a message from the daemon" ಬರುತ್ತೆ. ಪ್ರಯತ್ನಿಸಿದ್ದು:
daemon / no-daemon mode, heap 1536m → 512m, warm daemon, 5× retry,
clean env — ಎಲ್ಲಾ ಅದೇ ರೀತಿ 4–6 ಸೆಕೆಂಡ್ ನಲ್ಲಿ fail. JVM-to-JVM localhost
TCP test ಕೆಲಸ ಮಾಡಿತು, `gradlew --version` ಕೆಲಸ ಮಾಡಿತು — assemble task
ಮಾತ್ರ handshake ನಲ್ಲಿ ಸಿಲುಕುತ್ತೆ. ಇದು ಈ VM ನ sandbox/throttling ಸಮಸ್ಯೆ,
app code ಸಮಸ್ಯೆ ಅಲ್ಲ.

**ನಿಮ್ಮ PC / Mac ನಲ್ಲಿ (Flutter + Android Studio ಇದ್ದರೆ):**

```sh
cd avi-ai
flutter pub get
flutter analyze
flutter test
flutter build apk --release
# APK: build/app/outputs/flutter-apk/app-release.apk
```

ಅಥವಾ debug APK ಬೇಕಾದರೆ: `flutter run` (phone connect ಮಾಡಿ).

**ಈ VM ನಲ್ಲಿ ಮತ್ತೆ ಪ್ರಯತ್ನಿಸಬೇಕಾದರೆ** (SDK/JDK/Gradle ಎಲ್ಲಾ install ಆಗಿವೆ):

```sh
export PATH="$HOME/flutter-sdk/flutter/bin:$HOME/jdk17/bin:$PATH"
export JAVA_HOME=$HOME/jdk17 ANDROID_HOME=$HOME/android-sdk
export ANDROID_SDK_ROOT=$HOME/android-sdk GRADLE_USER_HOME=$HOME/.gradle
cd ~/workspace/avi-ai
flutter build apk --release
```

ಗಮನ: `~/.gradle/gradle.properties` ನಲ್ಲಿ proxy (hatch-egress-proxy:3128,
no-auth) + `org.gradle.jvmargs=-Xmx512m` ಇದೆ — ಬೇರೆ machine ನಲ್ಲಿ ಅದನ್ನು
ಅಳಿಸಿ/ಬದಲಾಯಿಸಿ. `android/gradle/wrapper/gradle-wrapper.properties`
standard URL ಗೆ restore ಮಾಡಲಾಗಿದೆ.
